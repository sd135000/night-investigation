# 夜行調查錄｜一個人也能跑的克蘇魯團（公開測試）

找不到團、約不到 KP，或只是半夜想自己跑一場？

《夜行調查錄》是《克蘇魯的呼喚》第七版的單人文字跑團。Claude 擔任守秘人，你用中文打出想做的事，他會描述場景、扮演 NPC、要求檢定。擲骰、理智、瘋狂、戰鬥、追逐和成長都由程式照規則結算，守秘人不會亂改結果，也不會替你決定。

## 可以玩到的東西

- 照第七版規則建角，114 種職業，分現代與非現代
- 16 個內建劇本，短篇到長篇都有，包含原創長篇《深淵之獅》；也能匯入自己的劇本
- 調查員跨劇本成長，經歷、舊傷、精神病史都會跟著角色走
- 招募 AI 隊友同行，羈絆會隨相處加深
- 大成功與大失敗各有獎勵表和懲罰表，大失敗還會累積「厄兆」
- 遇過的 NPC 會記得你，可能在之後的劇本以祖先或後代的身分再出現
- 擲骰動畫、場外提問、給守秘人的方向與雷點設定

## 怎麼玩

### 線上版（推薦）
用瀏覽器開啟 [遊戲連結](https://claude.ai/artifact/7ETpVACazpCfKXH2S5sYE2)。

- 需要 claude.ai 帳號，用的是你自己的 Claude 額度
- 雲端存檔，換裝置也能接著玩
- 可以開房間和朋友一起玩

### 下載版
到 [Releases](https://github.com/sd135000/night-investigation/releases) 下載最新的 zip。

1. 解壓縮整個資料夾
2. 用 Chrome 或 Edge 開啟「夜行調查錄.html」
3. 第一次開啟時貼上自己的 Anthropic API 金鑰（到 [console.anthropic.com](https://console.anthropic.com) 申請）

- 費用按用量計算，由你的 Anthropic 帳戶支付；建議在 Console 設定每月花費上限
- 存檔在本機瀏覽器，請定期用「設定 → 備份與還原」匯出
- 下載版不支援多人連線

下載後可以用 zip 旁邊的 `.sha256.txt` 核對檔案是否完整。

## 回報問題

- 遊戲內「設定 → 回報問題／建議」
- 或到 [Issues](https://github.com/sd135000/night-investigation/issues) 回報

目前是公開測試版，可能遇到 bug 或守秘人判斷怪怪的。守秘人由 AI 生成，偶爾會有不合理的描述，可以用「收回上一步」或「重新生成這段」。
